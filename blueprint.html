FinSnapshot
Design blueprint — architecture, data model, screen wireframes, and WebMCP tool specs.

What we're building

positioning
The problem

Finances are fragmented across five apps that show you data but can't reason over it. You open each one, do the maths yourself, and still can't answer "can I afford a holiday next month?"

The fix

Upload your bank statements. Set category rules once. Your full financial picture lives in one place — and because it's WebMCP-enabled, any AI agent can query it as structured data and actually answer real questions with your real numbers.

The gap we fill

Monarch, Copilot, Empower — none expose WebMCP tools. FinSnapshot is the first financial dashboard where your agent calls typed, schema-validated functions rather than scraping HTML. That's the differentiator.

Three design decisions

answered upfront
Where data comes from

No banking API. Every Australian bank exports CSV — CommBank, NAB, Westpac, ANZ, ING. Upload per account. Loans, property, and super: enter a current balance manually. No Plaid, no OAuth, no approval wait.

Where data lives

IndexedDB in the browser. No backend, nothing to deploy beyond the Next.js app. Survives page reloads, handles 100k+ transactions. Data never leaves the user's machine — a real privacy advantage over every SaaS competitor.

Categories and cashflow

Categories are SET by the user via rules, not guessed from bank strings. App ships with 15 defaults. Rules map description patterns to categories. Cashflow is 100% derived from categorised transactions — never separate data entry.

WebMCP tool specs

8 tools · navigator.modelContext.registerTool()
get_net_worth
Total assets, liabilities, net figure, and breakdown by type (cash, property, super, investments, debt). Agent can assess concentration and leverage without computing it.
assets: numberliabilities: numbernet_worth: numberbreakdown: array
get_accounts
All accounts with current balance, type, and institution. Optional type filter so the agent can ask for "only loans" without sifting everything.
type?: enumaccounts: Account[]
get_transactions
Recent transactions sorted by date desc. Filterable by account, category, date range, and amount — supports "show me my biggest expenses this month."
category?: stringdays?: numbermin_amount?: numbertransactions: Tx[]
get_spending_by_category
Category breakdown for last N days. With compare_previous_period true, returns delta so the agent can flag "dining up 38% vs prior period" without doing the maths itself.
days?: numbercompare_previous?: boolcategories: arraydelta?: number
get_cashflow
Monthly income vs expenses for last N months. Returns avg savings rate and trend direction (improving / declining / stable) pre-computed so the agent doesn't have to.
months?: numbermonths: arrayavg_savings_rate: numbertrend: string
get_portfolio
Investment holdings with current value and gain/loss per holding. Includes allocation breakdown by asset class so the agent can assess diversification directly.
sort_by?: enumholdings: arrayallocation: arraytotal_gain_pct: number
get_recurring_charges
Detects repeating transactions over the last 90 days — subscriptions and regular bills — grouped with total monthly cost. Agent can flag cancellation candidates.
subscriptions: arraytotal_monthly: number
get_financial_health_score
Synthesises key signals into a 0–100 score with rating and factor breakdown — savings rate, emergency fund months, debt-to-income, portfolio diversification. The demo centrepiece: one call gives the agent a structured health picture to narrate.
score: numberrating: stringfactors: array
